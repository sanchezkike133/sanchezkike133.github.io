# Mis primeros pasos con Astro

Astro es un framework moderno que me ha permitido desarrollar sitios web rápidos y bien organizados. Lo elegí porque facilita la creación de blogs y portafolios.

## ¿Por qué Astro?

Decidí aprender Astro por varias razones:

- Es muy rápido y genera sitios estáticos optimizados
- Permite usar componentes de manera sencilla
- Tiene una excelente documentación
- Es perfecto para blogs y portafolios

## Lo que aprendí

En el proceso aprendí a:

- Utilizar componentes reutilizables
- Crear layouts para estructurar mis páginas
- Organizar el contenido de manera eficiente
- Integrar otras tecnologías como TailwindCSS

## Próximos pasos

Este aprendizaje me motiva a continuar explorando nuevas herramientas para el desarrollo web. Planeo seguir mejorando este portafolio y experimentar con más funcionalidades de Astro.
